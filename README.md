# Synapse AWS Lambda Example

Example showing how to use [@pyrx/synapse](https://www.npmjs.com/package/@pyrx/synapse) with AWS Lambda + SAM.

## Setup

1. `npm install && npm run build`
2. `sam deploy --guided`

## Endpoints

- `POST /api/track` — Track an event
- `POST /api/identify` — Identify a contact
